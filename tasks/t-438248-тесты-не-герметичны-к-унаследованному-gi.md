`npm test`, запущенный из окружения с экспортированными `GIT_DIR`/`GIT_INDEX_FILE` (git-хук в linked worktree), даёт тест-хелперам, которые делают `git init`/`commit`/`config` во временных каталогах, писать в вызывающий репозиторий: коммиты `fixture` в ветку вызывающего worktree, ветки `alt`/`withextra`, переключение HEAD, `core.bare=true` и `[user] t@t` в общем `.git/config`, удаление файлов рабочего дерева; 401 тест падает.

Тестовая обвязка, которая спавнит git, сама снимает локальные GIT_*-переменные (`git rev-parse --local-env-vars`), чтобы ни один вызывающий (IDE, хук, агентский шелл) не мог повредить репо.

Репро: в linked worktree `GIT_DIR=$(git rev-parse --git-dir) npm test`.
