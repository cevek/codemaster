# Implementation backlog

The backlog is the `task-manager` (MCP; `tm` CLI): one `.md` per task under [`tasks/`](../tasks) —
git-native, byte-deterministic, queryable. How to file, triage and pick work: CONTRIBUTING.md
"Backlog discipline".

Fields and their values: [`tasks/config.yml`](../tasks/config.yml) (`tm explain_config`). Next task:
`npm run queue`.
